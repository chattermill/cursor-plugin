# Chattermill Cursor Plugin

The Chattermill plugin for [Cursor](https://cursor.com) provides access to your Chattermill workspace, enabling AI assistants to analyze customer feedback, explore themes, track metrics, and surface insights.

## Capabilities

- **Themes & Categories** — Browse and filter by your feedback taxonomy
- **Customer Feedback** — Search and retrieve verbatim feedback with flexible filters
- **Metrics** — Query NPS, CSAT, sentiment, and custom metrics over time
- **Observations** — Discover emerging patterns and clusters in feedback
- **Highlights** — Generate AI-powered summaries of feedback trends
- **Segments** — Filter by any attribute (country, brand, source, etc.)

## Installation

1. Open Cursor Settings
2. Navigate to the **Plugins** section
3. Browse the marketplace and search for **Chattermill**
4. Click **Install**
