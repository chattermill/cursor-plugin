# This plugin has moved

The Chattermill plugin now lives at **[chattermill/agent-plugins](https://github.com/chattermill/agent-plugins)**. The same plugin installs in Cursor, Claude Code, Codex, GitHub Copilot CLI and Gemini CLI, and it includes the `chattermill-best-practices` skill.

This repo gets no further updates and will be archived once the Cursor marketplace listing points at the new repo.

In Cursor, install **Chattermill** from Settings > Plugins. For every other agent, the [agent-plugins README](https://github.com/chattermill/agent-plugins#install) has the install command.
